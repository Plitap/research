# PLITAP · Исследования

Исследование открытых технических вопросов и сравнение возможных решений для PLITAP.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Постановка вопросов, критерии выбора и сравнение альтернатив.
- Экспериментальные стенды и воспроизводимые измерения.
- Отчёты, ограничения выводов и основания для будущих предложений.

## Границы направления

Исследовательский результат не становится правилом протокола автоматически. Изменения оформляются в [spec](https://github.com/Plitap/spec), а принятая реализация — в соответствующем репозитории. Внутренние архивы и прежние отчёты сюда не перенесены.

## Структура

| Раздел | Назначение |
|---|---|
| [`topics/`](topics/) | Исследовательские вопросы, варианты решений и критерии их оценки. |
| [`experiments/`](experiments/) | Изолированные эксперименты с описанием среды и способов воспроизведения. |
| [`reports/`](reports/) | Отчёты с фактическими результатами, ограничениями и следующими проверяемыми вопросами. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/research/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
